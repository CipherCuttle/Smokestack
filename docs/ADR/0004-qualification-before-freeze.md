# ADR-0004: Qualify Instruments Before Preregistering Detector

Status: ACCEPTED

## Context

Freezing thresholds before establishing source coverage, parser quality and reachability would preregister a broken measuring instrument rather than a hypothesis.

## Decision

Chronology is mandatory: source qualification -> temporal qualification -> formation calibration -> attention qualification -> detector preregistration -> prospective evaluation.

Calibration data may determine a later frozen rule, but cannot serve as that rule's confirmatory evaluation.
